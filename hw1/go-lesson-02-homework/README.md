# Домашнее задание к уроку №2:

Пять **независимых Go-модулей**. Задачи 1–4 — самостоятельно, 5 — мы разобрали на паре.

В каждом каталоге: `go.mod`, `README.md`, `<имя>.go` с **заготовкой функции** и `<имя>_test.go` с готовыми табличными тестами.

## Как работать

1. Откройте нужную папку задачи в терминале.
2. Прочитайте `README.md` и реализуйте `TODO` в `.go` файле.
3. Запустите `go test -v ./...` **в этой папке**.
4. Повторите для остальных задач.

Заготовки намеренно **не содержат решений**, поэтому тесты исходно не проходят — это ожидаемо. Не меняйте сигнатуры функций и тестовые файлы.

Используйте Go 1.22+; старайтесь ограничиться темами урока: типы, константы, if, for, range, switch, преобразования.

| Папка | Тема | Формат |
|---|---|---|
| `01_order_total` | Деньги и арифметика | Самостоятельно |
| `02_order_status` | `range` и `switch` | Самостоятельно |
| `03_unicode_name` | UTF-8 и `rune` | Самостоятельно |
| `04_safe_sum` | Проверка переполнения | Самостоятельно |
| `05_order_retry` | Циклы и остановка попыток | Разбор на паре |
