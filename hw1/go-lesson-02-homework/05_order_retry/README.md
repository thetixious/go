# Задача 5. Повторные попытки обработки заказа

**Разбор на паре · повышенная сложность**

Напишите `ProcessOrder(results []bool, maxAttempts int) (success bool, attempts int)`.

`results` содержит результаты последовательных попыток: `true` — успех, `false` — ошибка. Функция просматривает попытки **слева направо**, прекращая работу при первом успехе, при достижении `maxAttempts` либо при окончании `results`.

- `success` равен `true` только если среди реально выполненных попыток встретилось `true`.
- `attempts` — число реально просмотренных результатов, включая успешный.
- При `maxAttempts <= 0` и/или пустом списке попыток вернуть `(false, 0)`.
- Элементы после успешной попытки не учитываются.

Пример: `[]bool{false,false,true,false}`, `maxAttempts=3` → `(true,3)`.
