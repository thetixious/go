# Задача 1. Расчёт стоимости заказа

**Самостоятельная работа · базовая сложность**

Напишите `CalculateOrder(prices []int64, quantities []int, discount int) (subtotal, discountAmount, total int64)`.

- `prices` — цены товаров в копейках; `quantities` — соответствующие количества.
- Вычислите `subtotal = сумма(prices[i] * quantities[i])`.
- Скидка `discount` задана в целых процентах; вычисляйте её от `subtotal`, **округляя вниз до копейки**.
- `total = subtotal - discountAmount`.
- Верните три нуля, если длины срезов не совпадают, скидка вне диапазона `[0;100]`, цена отрицательна либо количество отрицательно.
- Пустые срезы одинаковой длины означают пустой заказ: `(0,0,0)`.
- Во входных данных не бывает арифметического переполнения `int64`.
- Не используйте `float64` для денежных вычислений.

Пример: `prices = []int64{19990,4990,12990}`, `quantities = []int{2,3,1}`, `discount = 10` → `(67940,6794,61146)` копеек.
