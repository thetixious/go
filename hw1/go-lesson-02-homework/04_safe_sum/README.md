# Задача 4. Безопасное суммирование

**Разбор на паре · повышенная сложность**

Напишите `SafeSum(transactions []int64) (total int64, skipped []int)`.

Суммируйте элементы **слева направо**, начиная с `total == 0`. Перед каждым сложением проверяйте переполнение `int64`. Если добавление безопасно — обновите `total`, иначе **не меняйте сумму** и запишите индекс отклонённой транзакции в `skipped`. Отрицательные транзакции разрешены; они уменьшают сумму. Если пропусков не было, `skipped` может быть `nil`.

Пример: `[]int64{1000,2500,9223372036854775800,100}` → `total == 3600`, `skipped == []int{2}`.

Разрешён `math` для `math.MaxInt64` и `math.MinInt64`. Само потенциально переполняющееся сложение выполнять до проверки нельзя.
