# Задача 3. Подсчёт символов в строке

**Самостоятельная работа · средняя сложность**

Реализуйте `AnalyzeName(name string) (byteCount, runeCount, latinCount, cyrillicCount int, positions []int)`.

- `byteCount`: число **байтов UTF-8** (`len(name)`).
- `runeCount`: число Unicode-кодовых точек, полученных через `range name`.
- `latinCount`: число букв, которые одновременно относятся к `unicode.Latin` и удовлетворяют `unicode.IsLetter`.
- `cyrillicCount`: аналогично для `unicode.Cyrillic`.
- `positions`: байтовые индексы начала каждой кодовой точки, **в порядке обхода**.
- Пробелы, цифры, символы и эмодзи не являются латинскими или кириллическими буквами.
- Строка гарантированно содержит корректный UTF-8. Для пустой строки верните нули и пустой срез (nil также допустим).

Пример: строка `"Кофе ☕ Go"` содержит 15 байт, 9 Unicode-кодовых точек, 2 латинские и 4 кириллические буквы, позиции `[0,2,4,6,8,9,12,13,14]`.
